# Step Guidance (v1.6) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the wizard's example placeholder texts with an on-demand (i) info button on every content step that opens a bottom-sheet explaining what to write, plus a README refresh (stack reference, current deploy story).

**Architecture:** A `StepHelp` content type and a `STEP_HELP` record live in `src/lib/stepHelp.ts` (pure content, no components). `src/components/ui.tsx` gains an `InfoSheet` bottom sheet (modeled on the existing `ConfirmSheet`) and `StepShell` gains an optional `help?: StepHelp` prop that renders the (i) button beside the title and owns the sheet's open state. Each wizard step component passes its `STEP_HELP` entry and drops its example placeholder.

**Tech Stack:** React 19 + TypeScript, Tailwind, framer-motion (AnimatePresence sheets), Vitest + React Testing Library.

## Global Constraints

- Help copy is fixed in this plan — use the strings in Task 1 **verbatim** (they were reviewed as part of the spec). Realistic Thinking step titles/questions on the screens themselves stay untouched (therapist's wording is verbatim-mandatory from v1.5).
- Placeholders to REMOVE (exact current values): SituationStep `"This afternoon at work, my manager…"`, ThoughtsStep `"“I always mess this up”"`, NegativeThoughtStep `"“I always mess this up”"`, AlternativeStep `"A more realistic way to see it…"`, BalancedStep `"A more even-handed way to see it…"`, EvidenceStep `'What backs it up…'`/`'What doesn’t add up…'`. Placeholders to KEEP: the three `"Name it…"` custom-emotion inputs (EmotionsStep, EmotionBeforeStep, EmotionNowStep).
- The (i) button appears on every content step in both formats (situation, emotions, thoughts, distortions, balanced, rerate, negativeThought, emotionBefore, evidenceFor, evidenceAgainst, alternative, emotionNow). NO (i) on ForkStep or DoneStep. Button `aria-label` is exactly `"About this step"`.
- Short step subtitles stay exactly as they are.
- Run tests with `npx vitest run <path>` (bare `npm test` is watch mode). Full gate: `npx vitest run && npm run build`.
- Work on branch `feat/step-guidance`. Never commit to `main`.
- Existing code style: 2-space indent, single quotes, tests colocated next to sources.

  emotionsClassic: {

```tsx
export function InfoSheet({
  open,
  help,
  onClose,
}: {
  open: boolean;
  help: StepHelp;
  onClose: () => void;
}) {
  const reduceMotion = useReducedMotion();
  return (
    <AnimatePresence>
      {open && (
        <motion.div
          initial={{ opacity: 0 }}
          animate={{ opacity: 1 }}
          exit={{ opacity: 0 }}
          className="fixed inset-0 z-50 flex items-end justify-center bg-ink/30 dark:bg-black/50"
          onClick={onClose}
        >
          <motion.div
            initial={reduceMotion ? { opacity: 0 } : { y: 80, opacity: 0 }}
            animate={{ y: 0, opacity: 1 }}
            exit={reduceMotion ? { opacity: 0 } : { y: 80, opacity: 0 }}
            transition={{ duration: 0.25, ease: 'easeOut' }}
            role="dialog"
            aria-modal="true"
            aria-label={help.title}
            className="w-full max-w-md rounded-t-3xl bg-paper p-6 pb-10 dark:bg-night-bg"
            onClick={(e) => e.stopPropagation()}
          >
            <h3 className="font-display text-xl font-medium">{help.title}</h3>
            <div className="mt-2 flex flex-col gap-2">
              {help.paragraphs.map((p, i) => (
                <p key={i} className="text-sm leading-relaxed text-mist dark:text-night-mist">{p}</p>
              ))}
            </div>
            {help.example && (
              <blockquote className="mt-4 rounded-2xl bg-sage-soft/60 p-4 text-sm italic leading-relaxed dark:bg-night-surface">
                Example: {help.example}
              </blockquote>
            )}
            <div className="mt-6">
              <Button onClick={onClose} className="w-full">
                Got it
              </Button>
            </div>
          </motion.div>
        </motion.div>
      )}
    </AnimatePresence>
  );
}
```

```tsx
export function StepShell({
  title,
  subtitle,
  kicker,
  help,
  children,
}: {
  title: string;
  subtitle?: string;
  kicker?: string;
  help?: StepHelp;
  children?: ReactNode;
}) {
  const reduceMotion = useReducedMotion();
  const [showHelp, setShowHelp] = useState(false);
  return (
    <motion.div /* existing motion props unchanged */>
      <div>
        {kicker && (
          <p className="mb-1 text-xs font-medium uppercase tracking-wide text-mist dark:text-night-mist">{kicker}</p>
        )}
        <div className="flex items-start justify-between gap-2">
          <h2 className="font-display text-2xl font-medium">{title}</h2>
          {help && (
            <button
              type="button"
              aria-label="About this step"
              onClick={() => setShowHelp(true)}
              className="mt-1 shrink-0 p-1 text-mist dark:text-night-mist"
            >
              <svg width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2" strokeLinecap="round">
                <circle cx="12" cy="12" r="9" />
                <path d="M12 16v-5" />
                <path d="M12 8h.01" />
              </svg>
            </button>
          )}
        </div>
        {subtitle && <p className="mt-1.5 text-sm leading-relaxed text-mist dark:text-night-mist">{subtitle}</p>}
      </div>
      {children}
      {help && <InfoSheet open={showHelp} help={help} onClose={() => setShowHelp(false)} />}
    </motion.div>
  );
}
```
