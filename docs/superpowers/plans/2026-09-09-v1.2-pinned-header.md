# Thought Records v1.2 Implementation Plan — Pinned Frosted Header & Scroll Cleanup

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pin a frosted, safe-area-aware header to the top of every browsing screen (Home, All records, record detail, Settings), and remove the dead scroll caused by doubled-up min-heights, plus safe-area insets under the two pinned bottom bars.

**Architecture:** One shared `AppHeader` component (sticky, translucent theme background with backdrop blur, full-bleed via `-mx-5`) replaces the four screens' inline headers. The App wrapper stops forcing `min-h-screen`/`pb-16` so short pages no longer scroll. The wizard keeps its own step header.

**Tech Stack:** unchanged.

## Global Constraints

- Work in `/work` on git branch `v1.2-layout` (branched off `main`). NEVER commit to `main`/`master`, never push, never deploy.
- `npx vitest run` for tests (never bare `vitest`); full suite (98 tests + new ones) must pass; `npm run build` clean; TypeScript strict.
- No copy changes anywhere; all existing accessible names stay (`Settings`, `Back`, `Edit`, `Continue`, `All records`, `Thought Records`).
- Frosted style: `bg-paper/80 backdrop-blur-md dark:bg-night-bg/80` — theme tokens only, works across all four themes automatically.
- Safe-area: header top padding `pt-[max(1rem,env(safe-area-inset-top))]`; pinned bottom bars get `pb-[max(2rem,env(safe-area-inset-bottom))]`. (Tailwind arbitrary values: no spaces inside the brackets.)
- The wizard's own header/footer chrome is NOT restructured — only its footer's `pb-8` gains the safe-area max().

- [ ] **Step 3: Write the component**

`src/components/AppHeader.tsx`:
```tsx
import type { ReactNode } from 'react';
import { Link } from 'react-router-dom';

export default function AppHeader({
  title,
  left,
  right,
}: {
  title?: string;
  left?: ReactNode;
  right?: ReactNode;
}) {
  return (
    <header className="sticky top-0 z-20 -mx-5 bg-paper/80 px-5 backdrop-blur-md dark:bg-night-bg/80">
      <div className="flex items-center gap-3 pb-3 pt-[max(1rem,env(safe-area-inset-top))]">
        {left}
        {title ? (
          <h1 className="min-w-0 flex-1 truncate font-display text-xl font-medium">{title}</h1>
        ) : (
          <span className="flex-1" />
        )}
        {right}
      </div>
    </header>
  );
}

export function BackLink({ to = '/' }: { to?: string }) {
  return (
    <Link to={to} aria-label="Back" className="-ml-2 p-2 text-mist dark:text-night-mist">
      <svg width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2" strokeLinecap="round" strokeLinejoin="round">
        <path d="M15 18l-6-6 6-6" />
      </svg>
    </Link>
  );
}
```
