# Swipe-to-Delete (v1.7) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every record card (home screen and All records list, open and completed) can be swiped left to reveal a Delete action that, after the existing confirmation sheet, permanently deletes the record.

**Architecture:** All behaviour lives in `src/components/RecordCard.tsx`: the card content becomes a horizontally draggable `motion.div` sliding over an absolutely-positioned Delete button; a module-level "one open card at a time" latch closes any previously revealed card; deletion reuses `deleteRecord()` + `ConfirmSheet`, and both list screens already use `useLiveQuery`, so the card disappears without any screen changes. The Delete button stays in the accessibility tree and reveals the card on keyboard focus, giving non-gesture users a real path.

**Tech Stack:** React 19 + TypeScript, framer-motion (drag), Dexie via existing repository, Vitest + RTL.

## Global Constraints

- Swipe applies to ALL record cards in both screens — no screen edits are needed or allowed (`HomeScreen.tsx`/`RecordListScreen.tsx` must not change).
- Deletion always goes through the confirmation sheet with the exact copy already used on the detail screen: title `"Delete this record?"`, body `"It will be gone from this device for good. If you've exported a backup, it stays in that file."`, confirm label `"Delete record"`.
- A plain tap on a non-revealed card navigates exactly as today (`/complete/:id` for open records when `openTo='wizard'`, else `/record/:id`). A tap on a revealed card closes the reveal and must NOT navigate. A drag must never trigger navigation.
- Only one card revealed at a time; scrolling closes the revealed card.
- Respect reduced motion: snap animations become instant (`duration: 0`) under `useReducedMotion()`.
- The existing list → detail → Delete path is untouched.
- Run tests with `npx vitest run <path>` (bare `npm test` is watch mode). Full gate: `npx vitest run && npm run build`.
- Branch `feat/swipe-delete`; never commit to `main`. Style: 2-space indent, single quotes.

- [ ] **Step 3: Implement the swipeable card**

Replace the `RecordCard` component in `src/components/RecordCard.tsx` with (imports at top of file: add `useEffect, useRef, useState` from `'react'`, `useReducedMotion` to the framer-motion import, `deleteRecord` from `'../lib/repository'`, `ConfirmSheet` from `'./ui'`):

```tsx
export type RecordCardTarget = 'wizard' | 'detail';

const REVEAL_WIDTH = 84;

// Only one card may be revealed at a time across the whole app.
let closeActiveCard: (() => void) | null = null;

export function RecordCard({
  record,
  openTo = 'wizard',
}: {
  record: ThoughtRecord;
  openTo?: RecordCardTarget;
}) {
  const reduceMotion = useReducedMotion();
  const [revealed, setRevealed] = useState(false);
  const [confirming, setConfirming] = useState(false);
  const dragging = useRef(false);

  const close = () => setRevealed(false);

  const reveal = () => {
    if (closeActiveCard && closeActiveCard !== close) closeActiveCard();
    closeActiveCard = close;
    setRevealed(true);
  };

  // Scrolling closes the revealed card.
  useEffect(() => {
    if (!revealed) return;
    window.addEventListener('scroll', close, { passive: true });
    return () => window.removeEventListener('scroll', close);
  }, [revealed]);

  const to =
    record.status === 'open' && openTo === 'wizard'
      ? `/complete/${record.id}`
      : `/record/${record.id}`;

  const remove = async () => {
    setConfirming(false);
    setRevealed(false);
    await deleteRecord(record.id!);
  };

  return (
    <div className="relative">
      <button
        type="button"
        aria-label="Delete record"
        onFocus={reveal}
        onClick={() => setConfirming(true)}
        className="absolute inset-y-0 right-0 flex w-[72px] items-center justify-center rounded-2xl bg-red-800/10 text-xs font-medium text-red-800/80 dark:bg-red-400/10 dark:text-red-400/80"
      >
        Delete
      </button>
      <motion.div
        drag="x"
        dragConstraints={{ left: -REVEAL_WIDTH, right: 0 }}
        dragElastic={0.05}
        animate={{ x: revealed ? -REVEAL_WIDTH : 0 }}
        transition={reduceMotion ? { duration: 0 } : { type: 'spring', stiffness: 400, damping: 40 }}
        onDragStart={() => {
          dragging.current = true;
          if (closeActiveCard && closeActiveCard !== close) closeActiveCard();
        }}
        onDragEnd={(_, info) => {
          const settled = (revealed ? -REVEAL_WIDTH : 0) + info.offset.x;
          if (settled < -REVEAL_WIDTH / 2) reveal();
          else close();
          // Let the post-drag click fire (and be suppressed) before clearing.
          setTimeout(() => {
            dragging.current = false;
          }, 0);
        }}
        whileTap={{ scale: 0.98 }}
        className="relative"
      >
        <Link
          to={to}
          draggable={false}
          onClick={(e) => {
            if (dragging.current || revealed) {
              e.preventDefault();
              close();
            }
          }}
          className="block rounded-2xl bg-surface p-4 shadow-sm dark:bg-night-surface"
        >
          {/* existing card content unchanged: date row, Unfinished badge,
              situation line, format-branched emotion chips */}
        </Link>
      </motion.div>

      <ConfirmSheet
        open={confirming}
        title="Delete this record?"
        body="It will be gone from this device for good. If you've exported a backup, it stays in that file."
        confirmLabel="Delete record"
        onConfirm={() => void remove()}
        onCancel={() => setConfirming(false)}
      />
    </div>
  );
}
```

Keep the existing JSX between `<Link>`'s tags byte-for-byte (the comment above marks where it goes). The old outer `motion.div whileTap` wrapper is replaced by this structure; `whileTap` moves onto the draggable div.
